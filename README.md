# Personal Website — leo-ricci.com

Clean, minimal personal landing page.

## Deploy

```bash
firebase login
firebase use --add          # select your Firebase project
firebase deploy --only hosting
```

## Structure

```
site/           → deployed to leo-ricci.com
  index.html    — personal landing page
```

The Shotgun AI product site (shotgun.leo-ricci.com) lives in the [shotgun-ai repo](https://github.com/ldricci3/shotgun-ai) under `website/`.
